## Funcionalidades do Sistema

* Interface criada com Bootstrap
* Carrossel de imagens na página inicial
* Exibição de produtos em formato de cards com imagem, descrição e preço
* Exibição dos serviços de banho e tosa em cards separados
* Formulário de cadastro com dados do cliente:
  * Nome, CPF, endereço, telefone, e-mail e sexo
* Cadastro de dados do pet:
  * Nome, raça e idade
* Sistema de agendamento com:
  * Escolha do serviço (banho ou tosa)
  * Tipo de atendimento (tele-busca ou no local)
  * Seleção de data e horário
* Validação dos campos do formulário (campos obrigatórios e e-mail válido)
* Exibição de mensagem de sucesso ao agendar utilizando Toast
* Limpeza automática do formulário após envio
* Uso de acessibilidade:
  * Atributo `alt` nas imagens
  * Labels nos campos do formulário
* Publicação do projeto no GitHub Pages
